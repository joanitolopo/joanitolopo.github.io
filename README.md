# Joanito Agili Lopo Portfolio

This is my personal portfolio hosted on GitHub Pages. It showcases my education, publications, projects, and experiences.

## Setup
1. Fork or clone this repository.
2. Customize the content in the HTML files.
3. Push to your GitHub repository.
4. Enable GitHub Pages in the repository settings under the "Pages" tab (use the `main` branch).

## Live Site
Once hosted, visit: `https://joanitolopo.github.io/joanito-portfolio/`
